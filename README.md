# ShopWise - Étude de cas

## Contexte

Projet réalisé dans le cadre de la formation **Expert en Ingénierie Logicielle (iSCOD)**.

Cette étude de cas vise à analyser les besoins de l'entreprise ShopWise et à proposer une solution technique adaptée, accompagnée d'une estimation des coûts et d'une analyse du retour sur investissement (ROI).

## Objectifs

- Analyser le besoin métier
- Concevoir une solution adaptée
- Estimer les coûts du projet
- Évaluer le retour sur investissement (ROI)
- Justifier les choix techniques retenus

## Choix techniques

- Application web responsive
- Base de données PostgreSQL
- Architecture modulaire
- Hébergement européen
- Notifications via Brevo ou Mailpro

## Livrables

- Analyse fonctionnelle
- Tableau des coûts estimés
- Analyse du ROI
- Justification des choix techniques
